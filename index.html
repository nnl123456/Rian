使用说明

1. 仓库配置：在「配置」标签填写 Owner / Repo / Branch / BASE_URL，点击保存后会记在本机浏览器里，下次打开自动生效。

2. 访问令牌：填写 GitHub Personal Access Token，经典令牌需要 repo 权限；细粒度令牌需要该仓库的 Contents 读写权限。点击「验证并保存」后会立即校验仓库可访问性。

3. 上传资产：可拖拽或点击选择多个文件，同名文件会自动覆盖。单个文件建议不超过 20MB，GitHub 上限为 100MB。

4. 对外链接：外链 = BASE_URL + 仓库内路径，可直接粘贴进 Markdown 或 HTML。

5. 批量操作：勾选多个资产后可批量复制外链或批量删除。

6. 换机迁移：用「导出配置 / 导入配置」迁移仓库参数；Token 出于安全考虑不会被导出，需要在新设备重新填写。

所有网络请求都直连 https://api.github.com，不经过任何第三方服务器。
